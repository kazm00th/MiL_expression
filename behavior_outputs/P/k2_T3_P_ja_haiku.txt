Python list dedup with order preservation: use `list(dict.fromkeys(my_list))`. This works in Python 3.7+ since dicts maintain insertion order. Alternative: iterate through list, tracking seen items in a set to build result list. Example: `result = []; seen = set(); [result.append(x) if x not in seen and seen.add(x) or True for x in my_list]; result`. The dict approach is simpler and faster.
