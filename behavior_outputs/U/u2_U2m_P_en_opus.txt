Default SQLite: 30 users on one server is far below its limits. Enable WAL mode and busy_timeout so writes queue instead of failing when many people clock in at once. Backups are a file copy and there is no DB server to run. Pick PostgreSQL IF you expect multiple app servers or containers, other tools (BI, reporting, other apps) need network DB access, you need DB-level roles or audit, you expect big growth or heavy concurrent writes, or your team already runs Postgres. Use an ORM or plain portable SQL so moving to Postgres later is cheap.
