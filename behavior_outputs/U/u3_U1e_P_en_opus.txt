It contradicts itself: summarizing at use time is still AI summarization, just done later, so summaries are not "no longer needed". It also generalizes from one uncited study (@study?) with no benchmark, baseline, or model given, so "doubled" can't be checked or assumed to transfer. "No RL needed" and "totally obsolete" overreach: showing one method improves doesn't show weight updates or curated skills and docs add nothing. It strawmans prior continual-learning work. And it ignores tradeoffs: raw logs cost storage, retrieval, context length, latency and privacy, while skills and docs give reuse, human review and cheap inference. Lossy versus lossless is a tradeoff, not a verdict.
