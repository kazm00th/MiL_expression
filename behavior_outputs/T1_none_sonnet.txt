Pythonでリストの重複を順序を保ったまま除く代表的な方法は以下の通りです。

1. dict.fromkeys を使う（Python 3.7+、最もシンプルで高速）
```python
lst = [1, 3, 2, 3, 1, 4]
result = list(dict.fromkeys(lst))
# [1, 3, 2, 4]
```
dictはPython 3.7以降で挿入順序を保持するため、この方法が定番です。

2. for文 + set で手動管理（要素がハッシュ可能な場合）
```python
seen = set()
result = []
for x in lst:
    if x not in seen:
        seen.add(x)
        result.append(x)
```
処理内容が明示的で分かりやすく、条件分岐を追加したい場合にも応用しやすい。

3. リスト内包表記 + set（やや技巧的）
```python
seen = set()
result = [x for x in lst if not (x in seen or seen.add(x))]
```
1行で書けるが可読性はやや落ちる。

4. 要素がハッシュ不可（リストや辞書など）の場合
setやdictのキーにできないため、順次比較する必要がある：
```python
result = []
for x in lst:
    if x not in result:
        result.append(x)
```
ただしこれはO(n^2)なので大きなリストには不向き。

補足：
- 順序を気にしないなら単純に `list(set(lst))` でよいが、Pythonのsetは順序を保証しないため今回の要件には合わない。
- 実用上は方法1（dict.fromkeys）が最も簡潔かつ効率的（O(n)）なので第一候補としておすすめ。
