割引ルール（レジ用）

P=2026/10/1〜12/31
S=セール品 → %割引×・券× (定価)
N=Σ(S以外)の金額(割引前)
会員%: G=10, Sv=5, 一般=0
d=会員%
IF 日付∈P:
  IF N≥10000 → d+=5
  IF 誕生月 ∧ 会員∈{G,Sv} → d+=3
d=min(d,15)
IF 500円券: 値引=max(N×d%, 500) ※%と券の併用×、得な方を選ぶ
ELSE: 値引=N×d%
支払=N−値引+S

例: G・誕生月・N=12000(P内) → d=10+5+3=18→15 → 値引1800 (>500なので%を使う)
