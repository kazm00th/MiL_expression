# 年末キャンペーン 割引ルール（レジ用）

## キャンペーン期間
**2026年10月1日〜12月31日**
- 期間中はこのページのルールをすべて使います。
- 期間外に使えるのは会員割引（ゴールド10%、シルバー5%）だけです。

## 1. まずセール品を分ける
- **セール品には割引もクーポンも使えません。** 定価のままお会計します。
- 手順2から手順5の計算は、**セール品以外の商品だけ**で行います。

## 2. %割引を足し算する（セール品以外の商品に適用）

| 項目 | 割引率 | 条件 |
|---|---|---|
| 会員割引 | ゴールド 10% / シルバー 5% / 一般 なし | 期間外でも使える |
| 1万円以上割引 | +5% | 期間中のみ。**セール品以外の合計が1万円以上**のとき |
| 誕生月割引 | +3% | 期間中のみ。**シルバー以上の会員**で、今月が誕生月のお客様 |

- 割引率は足し算で合わせます。
- **合計は15%が上限**です。15%を超えたら15%にします。
  - 例: ゴールド10% + 1万円以上5% + 誕生月3% = 18% → **15%**

## 3. 500円引きクーポンをお持ちの場合
- **%割引とクーポンは一緒に使えません。**
- 「%割引の金額」と「500円」を比べて、**お客様が得な方を使います。**
  - %割引の金額が500円より大きいとき → %割引を使う
  - %割引の金額が500円より小さいとき → クーポンを使う
- クーポンもセール品には使えません。

## 4. お支払い金額
**お支払い = (セール品以外の合計 − 割引額) + セール品の合計**

## 計算例（期間中）
1. **ゴールド・誕生月／セール品以外 12,000円、セール品 3,000円**
   割引率は10+5+3=18%なので15%。割引額は12,000×15% = 1,800円で、クーポン500円より得です。
   お支払いは10,200 + 3,000 = **13,200円**。
2. **一般／セール品以外 12,000円／クーポンあり**
   割引率は5%（1万円以上）で、割引額は600円。クーポン500円より得なので%割引を使います。お支払いは**11,400円**。
3. **シルバー（誕生月ではない）／セール品以外 4,000円／クーポンあり**
   割引率は5%で、割引額は200円。クーポン500円の方が得です。お支払いは**3,500円**。
4. **一般／セール品 8,000円、セール品以外 5,000円**
   セール品は1万円の計算に入れません。5,000円なので1万円以上割引はつきません。%割引はないので、クーポンがあれば500円引きになります。

---

## 店長に確認が必要な点
店長メモだけでは決まっていないため、配布する前に確認してください。
1. **期間外のクーポン**: 「期間外は会員割引だけ」は、クーポンも使えないという意味か。
2. **1万円の判定**: 割引前の金額で判定するか。税込か税抜か。
3. **1円未満の端数**: 切り捨てか、四捨五入か。
4. **誕生月の確認方法**: 会員情報で確認するか、身分証を見るか。
5. **同じ金額のとき**: %割引とクーポンが同じ額（例: ゴールドで5,000円なら500円同士）のとき、どちらを使うか。
6. **クーポンの対象額**: セール品以外の合計が500円未満のとき、クーポンをどう扱うか。
