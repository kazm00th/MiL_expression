# 年末キャンペーン 割引ルール（レジ担当者用）

## 1. キャンペーン期間
- **期間：2026年10月1日〜2026年12月31日**（初日と最終日も期間に含みます）
- **期間外：** 使えるのは会員割引（ゴールド10%、シルバー5%）だけです。1万円以上の5%割引と誕生月の3%割引は使えません。

## 2. 割引の対象にならない商品
- **セール品には、%の割引も500円引きクーポンも使えません。** セール品はいつも定価（売価）のままです。
- セール品の金額は、「1万円以上」の判定に入れません。
- %の割引とクーポンは、セール品を除いた商品（以下「対象商品」）にだけ使います。

## 3. %の割引（期間中）
次の割引を足し算して、対象商品の合計にかけます。

| 割引 | 条件 | 率 |
|---|---|---|
| 会員割引 | ゴールド会員 | 10% |
| 会員割引 | シルバー会員 | 5% |
| 会員割引 | 一般（会員でない方） | なし |
| 1万円以上割引 | 対象商品の合計が1万円以上（セール品は入れない） | +5% |
| 誕生月割引 | お客様の誕生月が、お買い上げの月と同じ。**シルバー会員とゴールド会員だけ**（一般のお客様は対象外） | +3% |

- **%の割引は合計15%までです。** 足して15%を超えるときは15%にします。
  - ゴールド＋1万円以上＋誕生月：10+5+3＝18% → **15%**
  - シルバー＋1万円以上＋誕生月：5+5+3＝**13%**
  - 一般＋1万円以上：**5%**（一般のお客様は誕生月でも+3%はつきません）

## 4. 500円引きクーポン
- **%の割引と一緒には使えません。** 1回の会計では、%の割引かクーポンのどちらか一方だけです。
- **値引き額が大きい方を使います。**
  - 例：対象商品の合計が3,000円で、%の割引が5%の場合 → %なら150円引き、クーポンなら500円引き → **クーポンを使う**
  - 例：対象商品の合計が12,000円で、%の割引が15%の場合 → %なら1,800円引き → **%の割引を使う**
- セール品にはクーポンも使えません。

## 5. 未確定の点（メモに書かれていないため、店長の確認が必要です）
1. 「1万円以上」は税込か税抜か。また、会員割引をする前の金額で判定するのか、した後の金額で判定するのか。
2. 期間外に500円引きクーポンを使えるか。
3. 誕生月をどうやって確認するか（会員証、身分証など）。
4. %で計算して1円未満の端数が出たとき、切り捨てるか、四捨五入するか。
5. %の割引とクーポンの値引き額が同じになったとき、どちらを使うか。
6. 対象商品の合計が500円未満のときにクーポンを使えるか（使える場合、0円まで引くのか）。
