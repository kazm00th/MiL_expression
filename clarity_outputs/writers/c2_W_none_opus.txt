# 年末キャンペーン 割引ルール（レジ用）

**キャンペーン期間：2026年10月1日〜12月31日**

## 1. まずセール品を分ける
- **セール品は割引もクーポンも使えません。** 定価で会計します。
- 割引は、**セール品を除いた金額**（以下「対象金額」）にだけかけます。

## 2. %割引を足し合わせる

| 割引 | 条件 | 期間中 | 期間外 |
|---|---|---|---|
| 会員割引 | ゴールド会員 | 10% | 10% |
| 会員割引 | シルバー会員 | 5% | 5% |
| 会員割引 | 一般のお客様 | なし | なし |
| 高額購入割引 | 対象金額が1万円以上（セール品は数えない） | +5% | なし |
| 誕生月割引 | 誕生月のお客様。**シルバー・ゴールド会員だけ** | +3% | なし |

- **合計の上限は15%です。** 15%を超えたら15%にします。
- 期間外は会員割引だけです。

## 3. 500円引きクーポンを持っているとき
- クーポンは%割引と**一緒に使えません**。
- 「%割引の金額」と「500円」を比べて、**お客様が得な方を1つだけ**使います。

## 早見表（期間中の%割引）

| | 1万円未満 | 1万円以上 | 1万円以上＋誕生月 |
|---|---|---|---|
| ゴールド | 10% | 15% | 15%（18%→上限15%） |
| シルバー | 5% | 10% | 13% |
| 一般 | 0% | 5% | 5%（誕生月割引なし） |

## 計算例（期間中）
- **ゴールド・誕生月、通常品12,000円＋セール品3,000円**
  → 10+5+3=18% → 上限で15%。12,000×15%=1,800円引き（クーポン500円より得）
  → 10,200円＋3,000円＝**13,200円**
- **シルバー、通常品6,000円、クーポンあり**
  → 5%=300円 < 500円なので**クーポンを使う** → **5,500円**
- **一般、通常品8,000円＋セール品4,000円**
  → 対象金額は8,000円なので1万円未満。%割引なし。クーポンがあれば500円引き。

## 店長に確認が必要な点
メモからは決められなかったので、確認してから配布することをおすすめします。
1. **クーポンは期間外にも使えるか**：「期間外は会員割引だけ」がクーポンも含むのかが不明です。
2. **1万円の判定は税込か税抜か**。会員割引をかける前の金額で判定するのか（上の例は割引前で判定）。
3. **一般のお客様にも高額購入割引の5%がつくか**：上の表ではつくものとしました。
4. **対象金額が500円未満のときのクーポン**：セール品には使えないので、何円まで引けるか。
5. **1円未満の端数**の処理（切り捨て・四捨五入など）。
6. **クーポンは1回の会計で1枚までか**。
