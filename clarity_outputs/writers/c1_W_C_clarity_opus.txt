# 年末キャンペーン 割引ルール（レジ担当者用）

## 1. 最初にセール品を分ける
- セール品には、会員割引・購入額割引・誕生月割引・500円引きクーポンのどれも使えません。常に表示価格のまま会計します。
- 1万円以上かどうかを見るときも、セール品の金額は入れません。
- 以下の割引とクーポンは、セール品を除いた商品（以下「通常品」）の合計金額だけにかけます。

## 2. 今日がキャンペーン期間かどうか確認する
- **期間：2026年10月1日〜2026年12月31日（初日と最終日を含む）**
- **期間外（2026年9月30日まで、2027年1月1日から）**：使えるのは会員割引だけです。
  - ゴールド会員：10%引き
  - シルバー会員：5%引き
  - 一般のお客様：割引なし
  - 購入額割引と誕生月割引は使えません。

## 3. 期間中の%割引（下の3つを足します）
| 割引 | 対象 | 率 |
|---|---|---|
| A. 会員割引 | ゴールド会員 | 10% |
|  | シルバー会員 | 5% |
|  | 一般 | 0% |
| B. 購入額割引 | 通常品の合計が10,000円以上のお客様（一般も含む） | 5% |
| C. 誕生月割引 | 今月が誕生月のシルバー会員またはゴールド会員（一般は対象外） | 3% |

- **A＋B＋Cの合計は15%までです。** 15%を超える場合は15%で会計します。
- 最大になる組み合わせ：
  - ゴールド会員：10＋5＋3＝18% → 上限の15%
  - シルバー会員：5＋5＋3＝13%
  - 一般のお客様：5%（Bだけ）

## 4. 500円引きクーポン
- クーポンと%割引（A、B、C）は一緒に使えません。
- 次の2つを比べて、お客様が得になる方だけを使います。
  - %割引の額（通常品の合計 × 3で決まった率）
  - 500円
- 例：ゴールド会員（期間外、10%）の場合、通常品の合計が5,000円を超えると%割引の方が得です。合計がちょうど5,000円なら、どちらでも同じ金額です。
- セール品にはクーポンも使えません。
