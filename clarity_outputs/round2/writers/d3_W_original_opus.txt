冬キャンペーン 割引ルール（レジ用）

定義: P=2026/12/1〜2027/2/28 ; N=通常品計(割引前) ; S=セール品計 ; 全額税抜 ; 1円未満切捨

1. %率r（Nのみに適用、Sには使えない）
 r = 会員率(ゴールド10 / シルバー5 / 一般0) ※P外でも適用
 + IF P: N≥20,000→8 | N≥10,000→5（どちらか一方のみ）
 + IF P ∧ 誕生月 ∧ シルバー以上: 3
 r上限15（ゴールド∧誕生月: 上限18）

2. 支払方法（どちらか1つ。併用不可。安い方を選ぶ）
 A(%割引): N'=floor(N×(1−r%)) ; 商品額=N'+S
 B(500円クーポン, 1会計1枚, P外も可, Sにも可): 商品額=N+S−500

3. 送料（配送時のみ）
 ゴールド→0 ; それ以外: N'≥5,000→0 ; <5,000→600

4. ポイント
 IF P ∧ ¬クーポン: floor(商品額×1%)（送料は含めない）
 P外またはクーポン使用時→0

請求額=商品額+送料
