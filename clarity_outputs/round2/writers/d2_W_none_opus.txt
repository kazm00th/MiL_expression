# 冬のキャンペーン 割引ルール（レジ担当用）

**期間：2026年12月1日〜2027年2月28日**
金額はすべて税抜です。1円未満は切り捨てます。

---

## 1. はじめに：商品を2つに分ける
- **通常品**：%割引の対象です。「1万円／2万円」「送料無料5,000円」を判定するときの金額にも入れます。
- **セール品**：%割引の対象外で、判定の金額にも入れません。500円クーポンは使えます。

## 2. %割引の率を決める（通常品だけに使う）
次の率を**足し合わせます**。

| 項目 | 条件 | 率 | 期間外 |
|---|---|---|---|
| 会員割引 | ゴールド | 10% | あり |
| | シルバー | 5% | あり |
| | 一般 | なし | ― |
| まとめ買い | 通常品の合計（割引前）が1万円以上2万円未満 | +5% | なし |
| | 通常品の合計（割引前）が2万円以上 | +8%（5%と重ねない） | なし |
| 誕生月 | シルバー・ゴールドで、今月が誕生月 | +3% | なし |

**上限**：合計は15%までです。ただし**ゴールドで誕生月**の人は18%までです。

よくある組み合わせ（期間中・通常品2万円以上のとき）
- ゴールド・誕生月：10+8+3=21% → **18%**
- ゴールド：10+8=18% → **15%**
- シルバー・誕生月：5+8+3=16% → **15%**
- シルバー：5+8=13%
- 一般：8%

割引額 = 通常品の合計 × 率（1円未満切り捨て）

## 3. 500円クーポン
- **%割引（会員割引を含む）とは一緒に使えません。** 得な方を選びます。%割引の額が500円より少なければクーポンを使います。
- クーポンを使うときは%割引を一切かけず、「通常品＋セール品」の合計から500円を引きます。
- 期間外でも使えます。セール品だけの会計でも使えます。
- 1会計につき1枚までです。

## 4. 送料（配送のときだけ）
- **ゴールド会員**：いつでも無料
- それ以外：%割引をかけた後の**通常品の合計**で決めます。
  - 5,000円以上なら無料
  - 5,000円未満なら600円
  - セール品は含めません。

## 5. ポイント（期間中だけ）
- 支払額（送料を除き、セール品を含む）の1%を付けます。1円未満は切り捨てです。
- **クーポンを使った会計にはポイントを付けません。**
- 期間外はポイントを付けません。

## 6. レジでの手順
1. 期間内か確認し、会員ランクと誕生月を確認する
2. 通常品とセール品に分けて、それぞれの合計を出す
3. %割引の率を出す（上限に注意）→ 割引額を計算する
4. クーポンがあれば、割引額と500円を比べて得な方にする
5. 配送なら送料を決める
6. 支払額を出す → 期間中でクーポンを使っていなければポイントを付ける

## 7. 計算例
**例1** 期間中・シルバー・誕生月、通常品22,000円、セール品3,000円、配送、クーポンあり
- 率：5+8+3=16% → 上限で15%。割引額は3,300円で、500円より得なので%割引を使う
- 通常品 18,700円 ＋ セール品 3,000円 ＝ **21,700円**
- 送料：通常品が18,700円で5,000円以上なので無料
- ポイント：217ポイント

**例2** 期間中・一般、通常品4,000円、セール品2,000円、配送、クーポンあり
- 率：0%（1万円未満のため）→ クーポンを使う
- 6,000円 − 500円 ＝ 5,500円
- 送料：通常品が4,000円で5,000円未満なので600円 → 支払額 **6,100円**
- ポイント：なし（クーポンを使ったため）

**例3** 期間外・ゴールド、通常品3,000円、配送、クーポンあり
- 会員割引10%は300円で、500円より少ない → クーポンを使う（会員割引はなし）
- 3,000円 − 500円 ＝ **2,500円**。ゴールドなので送料は無料。期間外なのでポイントはなし

## 店長に確認したい点
ここまでのルールは、下の「仮の扱い」を前提にして書いています。

1. **%割引は足し算でよいか**：「さらに5%」を率の足し算（10%+5%=15%）と読みました。順番に掛けていく計算（0.9×0.95）ではない、という理解でよいですか。
2. **「得な方」の比べ方**：割引額だけで比べるのか、送料やポイントも含めて比べるのか。
   - 例：シルバー・期間外・通常品5,200円・配送のとき
     - %割引（260円）を選ぶと、通常品が4,940円になり送料600円がかかります。
     - クーポンを選ぶと、割引前は5,200円なので送料が無料になる可能性があります（3番とも関係します）。
   - 割引額がちょうど500円で同じとき（例：一般・通常品1万円・5%）は、どちらにしますか。ポイントが付くかどうかが変わります。
3. **クーポンを使ったときの送料判定**：「%割引後の通常品の合計」は、クーポンを使った場合は割引前の通常品の合計で見てよいですか。500円を引いた後の金額で見ますか。
4. **送料ルールは期間外も同じか**：「期間外は会員割引だけ」と書かれていますが、送料ルールとクーポンは期間外も使えると読みました。期間外にポイントがないことも含めて、この理解でよいですか。
5. **クーポンが合計金額を上回るとき**（例：セール品300円だけ）は、0円にしてよいですか。それとも使えないことにしますか。
6. **判定する日付**：配送や取り置きの場合、期間や誕生月は注文日・会計日・出荷日のどれで判定しますか。
7. **切り捨てのタイミング**：割引額は合計に対して1回だけ切り捨てるのか、商品ごとに計算して切り捨てるのか。
8. **ゴールド・シルバー会員がクーポンを使うと会員割引がなくなる**：メモどおりだとこうなりますが、それで意図どおりですか。お客様から質問が出やすい点です。
