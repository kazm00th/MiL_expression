冬キャンペーン割引ルール（レジ用）

定義
P:=2026/12/1–2027/2/28
N:=通常品計(割引前) ; S:=セール品計
全額税抜 ; 1円未満切捨て

①%割引 r（N∈対象，S∉対象）
r=Σ{
 会員: G10%|Si5%|一般0%
 P∧N≥20000: +8%
 P∧10000≤N<20000: +5%
 P∧誕生月∧会員∈{G,Si}: +3%
}
r≤15% ; G∧誕生月: r≤18%
¬P → r=会員分のみ
N':=⌊N×(1−r)⌋
案A: 小計=N'+S

②500円券（B）
¬(A∧B)．r=0
小計=N+S−500
1枚/会計 ; ¬P可 ; S含む
A|B → 得な方

③送料 IF 配送
G → 0（常時）
N'≥5000 → 0 ; else 600
（B時 N'=N）

④pt IF P∧¬B
⌊小計(送料除)×1%⌋

確認事項
Q1 r: 単純加算？(例 G誕生月: 10+8+3=21→18%) or 逐次掛け？
Q2 A|B「得」の比較: 小計のみ？送料・pt込み？
Q3 B時の送料判定: N？ or N−500？
Q4 N+S<500 → 0円？
Q5 切捨て: 各段？ or 最終のみ？
Q6 P・誕生月の判定日: 会計日？（配送日≠）
