# 冬季キャンペーン 割引・送料・ポイント算出ルール

## 0. 用語・入力・前提
- 金額はすべて税抜。%計算等で1円未満の端数が出た場合は都度切り捨て（floor）。
- 「通常品」＝セール対象でない通常価格の商品、「セール品」＝セール対象商品。各明細にこの区分が付与されている前提。
- 会員ランク：ゴールド／シルバー／一般（一般＝会員割引0%の基本ランク）。
- キャンペーン期間：2026-12-01〜2027-02-28（取引日時で判定）。
- 誕生月：会員登録上の誕生月と取引日の月が一致するか。
- 必要な入力：取引日、会員ランク、誕生月フラグ、通常品小計（割引前）、セール品小計（割引前）、受け取り方法（配送／それ以外）、クーポン提示有無（1会計1枚まで）。

## 1. 小計
- 通常品小計＝通常品の明細金額合計（割引前）
- セール品小計＝セール品の明細金額合計（割引前）
- 後述の「1万円／2万円」判定は必ずこの割引前の通常品小計を使う（セール品は含めない）。

## 2. 会員%割引率（基本、期間内外を問わず常に適用）
- ゴールド：10%　シルバー：5%　一般：0%

## 3. キャンペーン加算%（期間中のみ、上記に加算）
- 数量ボーナス（通常品小計・割引前で判定、5%と8%は排他で高い方のみ採用）
  - 通常品小計 ≥ 20,000円 → +8%
  - 10,000円 ≤ 通常品小計 ＜ 20,000円 → +5%
  - それ未満 → +0%
- 誕生月ボーナス：シルバー以上（シルバー・ゴールド）かつ誕生月 → +3%（一般は対象外）

## 4. %割引率の上限
- ゴールドかつ誕生月かつ期間中 → 上限18%
- それ以外 → 上限15%
- 最終%割引率 ＝ min(2+3の合計, 上限)
  ※ゴールドが誕生月でなくても数量ボーナスとの合算で18%相当になり得るが、その場合も上限15%でカットする。

## 5. %割引額
- 通常品%割引額 ＝ floor(通常品小計 × 最終%割引率)
- セール品には%割引（会員割引を含む全ての%割引）を一切適用しない（セール品の%割引額は常に0）。

## 6. 500円クーポンとの排他選択
- クーポンと%割引は併用不可。クーポンが提示された会計では、割引額が大きい方を採用する。
  - 案A（%割引採用）：割引額＝5.の通常品%割引額
  - 案B（クーポン採用）：割引額＝500円（ただし通常品小計＋セール品小計が500円未満の場合はその合計額を上限とする）。通常品・セール品の合計から差し引く。
- クーポン未提示の会計では常に案A（%割引、あれば）を適用する。
- クーポンはキャンペーン期間外でも使用可（期間外は案Aの割引額＝会員割引額のみとの比較になる）。

## 7. 商品代金（請求額のうち商品分）
- 案A採用時：商品代金 ＝（通常品小計－通常品%割引額）＋セール品小計
- 案B採用時：商品代金 ＝ 通常品小計＋セール品小計－クーポン額

## 8. 送料（配送の場合のみ発生。それ以外の受け取りは送料なし）
- ゴールド会員 → 常に送料無料（期間内外・案A/案Bを問わない）
- ゴールド以外：
  - 判定基準額＝「%割引後の通常品小計」＝ 通常品小計－通常品%割引額（案B採用時は%割引が適用されていないため通常品%割引額＝0を用いる。クーポン控除はこの判定に影響させない）
  - 判定基準額 ≥ 5,000円 → 送料無料、それ未満 → 送料600円

## 9. ポイント付与
- キャンペーン期間中の会計のみ対象。期間外は付与なし。
- 案B（クーポン使用）の会計はポイント付与なし。
- 上記以外（期間中かつ案A）：付与ポイント＝floor(商品代金 × 1%)（送料は含めない）

## 10. 最終請求額
- 請求額（税抜）＝ 商品代金（7.）＋送料（8.）　※消費税はこの後段で別途加算。

## 計算手順まとめ（擬似コード）

```
期間内 = 2026-12-01 <= 取引日 <= 2027-02-28

rate = {gold:10, silver:5, general:0}[ランク]
if 期間内:
    if 通常品小計 >= 20000: rate += 8
    elif 通常品小計 >= 10000: rate += 5
    if ランク in {silver, gold} and 誕生月: rate += 3
cap = 18 if (ランク == gold and 誕生月 and 期間内) else 15
rate = min(rate, cap)
percent_discount = floor(通常品小計 * rate / 100)   # セール品には不適用

if クーポン提示:
    coupon = min(500, 通常品小計 + セール品小計)
    採用 = "クーポン" if coupon > percent_discount else "%割引"
else:
    採用 = "%割引"

if 採用 == "%割引":
    used_percent = percent_discount; used_coupon = 0
    商品代金 = (通常品小計 - used_percent) + セール品小計
else:
    used_percent = 0; used_coupon = coupon
    商品代金 = 通常品小計 + セール品小計 - used_coupon

if 受け取り == 配送:
    if ランク == gold:
        送料 = 0
    else:
        基準額 = 通常品小計 - used_percent
        送料 = 0 if 基準額 >= 5000 else 600
else:
    送料 = 0

ポイント = floor(商品代金 * 0.01) if (期間内 and 採用 != "クーポン") else 0
請求額(税抜) = 商品代金 + 送料
```

## 確認したい点
1. 「%割引はセール品には使えない」は、キャンペーンの上乗せ分（5%/8%/3%）だけでなく会員割引（10%/5%）自体もセール品には適用しない、という解釈でよいか（本ルールはそう解釈）。
2. 数量条件ボーナス（5%/8%）は会員ランクを問わず一般会員にも適用される、という解釈でよいか。
3. %割引の上限判定・端数処理は、各種率を合算してから一度だけ行う（個々の割引を都度切り捨てて積み上げるのではない）という解釈でよいか。
4. 送料ルール（通常品5,000円以上で無料／ゴールドは常時無料）は、キャンペーン期間外でも常時有効な通常運用ルールという理解でよいか（メモの記載位置から期間限定の可能性も否定できない）。
5. 送料の無料判定にセール品の金額は一切含めない（通常品合計のみで判定する）という理解でよいか。
6. クーポン使用時、送料の無料判定基準額は「クーポン控除前・%割引なし」の通常品小計をそのまま使う（クーポンは送料判定に影響しない）という理解でよいか。
7. 「得な方にする」の比較は%割引額とクーポン500円の直接比較のみを指し、送料やポイントへの波及効果（%割引を選ぶと送料無料ラインを超える等）は考慮しないという理解でよいか。
8. %割引額とクーポン額がちょうど同額の場合、どちらを優先するか（ポイント付与の有無が変わるため定義が必要）。
9. クーポン利用時、通常品＋セール品合計が500円未満の場合はクーポン額を合計金額まで減額し代金がマイナスにならないようにする、という理解でよいか。
10. 会員ランクが判定できない注文（非会員・ゲスト等）は発生し得るか。発生する場合は「一般」と同一に扱ってよいか。
11. 「誕生月」は取引日の月と登録誕生月が一致するかのみで判定し、年は問わないという理解でよいか。
12. キャンペーン期間の終了日（2027/2/28）は当日中の取引を含む（期間内）という理解でよいか。
