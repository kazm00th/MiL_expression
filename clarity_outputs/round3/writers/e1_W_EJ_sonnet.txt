金額は税抜。計算はすべて1円未満切り捨て(floor)。

期間(以下「期間中」): @会計日が2026-12-01〜2027-02-28(両端含む)。

R=通常品合計、S=セール品合計(ともに割引前・税抜)。%割引は常にRのみに適用し、Sには適用しない。

M(会員割引、常時適用): @会員ランク ゴールド→10 / シルバー→5 / 一般→0。

V(数量割引、Rの割引前金額で判定、Sは含めない): IF 期間外 THEN V=0。ELIF R>=20000 THEN V=8。ELIF R>=10000 THEN V=5。ELSE V=0。(5と8は非併用、高い方のみ)

B(誕生月割引): IF 期間外 THEN B=0。ELIF (@会員ランク=シルバー OR ゴールド) AND @会計月=@登録誕生月 THEN B=3。ELSE B=0。

D=M+V+B。cap: IF @会員ランク=ゴールド AND @会計月=@登録誕生月 THEN cap=18。ELSE cap=15。D=min(D,cap)。

R'=floor(R*(100-D)/100)(%割引適用時の通常品合計)。A=R'+S(%割引採用時の商品合計)。

クーポン(500円、税抜、R+Sの合計から減算、期間外・セール品にも使用可、1会計1枚、%割引と併用不可): C=R+S-500(クーポン採用時の商品合計)。

採否: IF C<A THEN クーポン採用、確定通常品合計Rf=R(%割引なし)。ELSE %割引採用(クーポン不使用)、Rf=R'。

送料(@配送方法=配送の時のみ発生。それ以外は常に0): IF @会員ランク=ゴールド THEN 0。ELIF Rf>=5000 THEN 0。ELSE 600。

ポイント: IF 期間外 OR クーポン採用 THEN 0。ELSE floor((Rf+S)*0.01)。(送料を除く支払額の1%)

確認したい点:
クーポン採否の自動判定は商品合計(AとC)だけの比較でよいか、送料差やポイント喪失も含めた比較にすべきか。
クーポン採用時、送料判定に使うRfは割引前の通常品合計Rそのものという理解でよいか。
上限18%はゴールドかつ誕生月の両方成立時のみで、どちらか一方だけなら15%、という理解でよいか。
会員ランク・登録誕生月の取得元と、@会計月・@会計日の基準(タイムゾーン等)を教えてほしい。
