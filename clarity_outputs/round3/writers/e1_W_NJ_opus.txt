# 冬のキャンペーン 割引ルール（会計エージェント用）

【仮】が付いた項目は、店長メモから解釈して決めた暫定ルールです。末尾の確認事項に回答が出るまでは、このとおりに処理します。

## 1. 前提と用語
- 金額はすべて税抜です。消費税の計算はこのルールの対象外で、既存の処理どおりに行います。
- 1円未満は切り捨てます（2-7、5-3）。
- キャンペーン期間は2026年12月1日〜2027年2月28日です（両日を含む、日本時間）。会計日で判定します。【仮・Q6】
- 通常品：セール品以外の商品。セール品：店がセール対象にしている商品。
- R：通常品の合計（割引前の価格 × 数量）
- S：セール品の合計（セール価格 × 数量）
- 会員ランクはゴールド／シルバー／一般の3つで、会計時点のランクを使います。非会員は一般として扱います。【仮・Q7】
- 誕生月：会計日の月が、会員情報に登録された誕生月と同じであること。

## 2. %割引（通常品だけに掛ける）
- 2-1. 会員割引（期間の内外とも）：ゴールド10%、シルバー5%、一般0%。
- 2-2. まとめ買い割引（期間中のみ）：Rが2万円以上なら8%、1万円以上2万円未満なら5%、1万円未満なら0%。5%と8%は重ねません。判定は割引前のRで行い、セール品は含めません。
- 2-3. 誕生月割引（期間中のみ）：誕生月のシルバーとゴールドに3%。一般は対象外です。
- 2-4. 率は足し算します（掛け算にはしない）。合計の上限は15%です。ただし、期間中に誕生月を迎えているゴールドは上限18%です。
- 2-5. 期間外は2-1の会員割引だけです。まとめ買い割引と誕生月割引は付きません。
- 2-6. %割引はセール品にも送料にも掛けません。
- 2-7. 割引後の通常品合計は R' = R ×（100 − 適用率）÷ 100 で求め、1円未満を切り捨てます。Rにまとめて1回だけ掛け、商品ごとには計算しません。【仮・Q2】

期間中の適用率（上限を当てた後。カッコ内は上限を当てる前の合計）

| ランク | Rが1万円未満 | 1万円以上2万円未満 | 2万円以上 |
|---|---|---|---|
| ゴールド・誕生月 | 13% | 18% | 18%（21%） |
| ゴールド | 10% | 15% | 15%（18%） |
| シルバー・誕生月 | 8% | 13% | 15%（16%） |
| シルバー | 5% | 10% | 13% |
| 一般 | 0% | 5% | 8% |

期間外は、Rの金額に関係なくゴールド10%、シルバー5%、一般0%です。

## 3. 500円クーポン
- 3-1. 1会計に1枚までです。2枚以上出されても1枚だけ使います。期間の内外とも使えます。
- 3-2. %割引とは併用できません。クーポンを使う会計では、会員割引を含む%割引を一切掛けません。
- 3-3. R + S（割引前の通常品とセール品の合計）から500円を引きます。送料からは引きません。R + S が500円未満なら商品代金は0円とし、余った分は送料に回しません。【仮・Q5】
- 3-4. 客がクーポンを出したら、A案（%割引）とB案（クーポン）の両方を6章の手順で計算します。支払額（商品代金＋送料）が小さい方を採用し、同額ならA案にします。【仮・Q1】
- 3-5. A案を採用したときはクーポンを使わず、客に返します。

## 4. 送料
- 4-1. 送料は配送のときだけかかります。配送でなければ0円です。
- 4-2. ゴールドは期間や金額に関係なく0円です。
- 4-3. ゴールド以外は、%割引後の通常品合計が5,000円以上なら0円、5,000円未満なら600円です。セール品は判定に含めません。
  - A案は R' で判定します。
  - B案は%割引がないので R で判定します。クーポンの500円は引かずに判定します。【仮・Q4】
  - 注意：まとめ買い割引は割引前の R で、送料は%割引後の R' で判定します。判定の基準が違います。
- 4-4. 4-3のルールは期間外にも適用します。【仮・Q3】

## 5. ポイント
- 5-1. ポイントは期間中の会計だけに付けます。期間外は付けません。
- 5-2. クーポンを使った会計（B案を採用した会計）には付けません。クーポンを出してもA案になった会計には付けます。
- 5-3. ポイントは、商品代金（メモでいう「支払額（送料を除く）」、税抜）の1%です。1ポイント未満は切り捨てます。A案の商品代金は R' + S です。
- 5-4. 非会員には付けません（付与先がないため）。【仮・Q7】

## 6. 計算手順
1. 期間中かどうか、会員ランク、誕生月かどうか、配送かどうか、クーポンの提示があるかを確かめる。
2. R と S を出す。
3. 2章の表で適用率を決める。
4. A案を計算する。R' を出す → 商品代金A = R' + S → 送料Aを R' で判定 → 支払額A = 商品代金A + 送料A → ポイントA（期間中なら商品代金Aの1%、切り捨て）。
5. クーポンの提示があればB案を計算する。商品代金B = R + S − 500（0円未満にしない）→ 送料Bを R で判定 → 支払額B = 商品代金B + 送料B → ポイントBは0。
6. クーポンがなければA案にする。クーポンがあれば支払額の小さい方を採用し、同額ならA案にする。
7. 採用した案の商品代金と送料を税計算に渡す。
8. このルールで決められないケースは、推測で確定せず担当者に確認する。

## 7. 計算例
例1：期間中、ゴールド、誕生月、配送、クーポンなし。R = 24,000、S = 3,000
- 率は 10 + 8 + 3 = 21% で、上限により18%。R' = 24,000 × 0.82 = 19,680
- 商品代金 22,680、送料0（ゴールド）、支払額 22,680、ポイント226（226.8を切り捨て）

例2：期間中、シルバー（誕生月ではない）、配送、クーポンあり。R = 5,200、S = 1,000
- A案：率5%で R' = 4,940。5,000円未満なので送料600。支払額 4,940 + 1,000 + 600 = 6,540、ポイント59
- B案：商品代金 6,200 − 500 = 5,700。送料は R = 5,200 で判定して0。支払額 5,700、ポイント0
- 支払額が小さいB案を採用する。

例3：期間中、一般、店頭受け取り、クーポンあり。R = 10,000、S = 0
- A案：1万円ちょうども対象なので率5%。支払額 9,500、ポイント95
- B案：支払額 9,500
- 同額なのでA案を採用し、クーポンは客に返す。

## 確認事項（店長への質問。回答が出るまでは上の【仮】で処理する）
- Q1. 「得な方」の基準：今は支払額（商品代金＋送料）だけで比べています。A案にだけ付くポイントや、クーポンが手元に残ることも考えますか。たとえば期間中のシルバーで R = 9,000、S = 5,000、店頭受け取りの場合、B案の方が50円安くなりますが、A案なら135ポイント付きます。今のルールではB案になります。
- Q2. 端数処理：今は%割引を R にまとめて掛け、割引後の金額を切り捨てています（客に有利な方法）。割引額の方を切り捨てるのか、商品ごとに計算するのかを確認させてください。たとえば9,999円の5%引きは、今のルールでは9,499円、割引額を切り捨てると9,500円になります。
- Q3. 送料の5,000円ルールは期間外にも適用しますか。今は通年で適用しています。また「ゴールドはいつでも無料」は、期間外も含むという意味に読んでいます。
- Q4. 送料の判定に使う金額は次の2点でよいですか。(a) クーポン会計では割引前の R で判定し、クーポンの500円は引いていません。(b) セール品は判定に含めないので、セール品だけを配送するとゴールド以外は常に送料600円になります。
- Q5. クーポンの利用条件：商品代金が500円未満のときは0円までとし、余った分は送料に回していません。最低購入額などの条件はありますか。
- Q6. 期間の判定日：今は会計日で判定しています。配送で注文日と発送日が期間をまたぐ場合は、どちらの日で判定しますか。
- Q7. 非会員の扱い：今は一般と同じ扱い（会員割引なし、誕生月割引なし、まとめ買い割引は対象）とし、ポイントは付けていません。メモの「一般」は非会員のことですか、それとも会員ランクの一つですか。
