# 冬季キャンペーン割引ルール(会計処理エージェント向け)

## 0. 会計ごとに必要な入力情報
- 会計日
- 会員ランク: gold / silver / general(一般)
- 誕生月フラグ: 会計日の月が、当該会員の誕生月と一致するか
- 通常品小計 R(税抜・割引前の合計)
- セール品小計 S(税抜・割引前の合計)
- 受け取り方法: 配送 / 店頭
- クーポン利用希望フラグ: この会計で500円クーポンを使う意思があるか

## 共通原則
- R1. 金額はすべて税抜で扱う。
- R2. 割合(%)計算により1円未満の端数が生じた場合は、その都度切り捨てる(floor)。

## 1. キャンペーン期間の判定
- R3. 会計日が 2026-12-01〜2027-02-28 の範囲内なら「期間内」、それ以外は「期間外」。
- R4. 期間外の会計に適用する割引は、下記R5の会員割引のみ。R6・R7の加算割引は一切適用しない。

## 2. %割引率の算出
- R5. 会員基本割引率 M(期間の内外を問わず適用): ゴールド10%/シルバー5%/一般0%。
- R6.(期間内のみ)購入金額加算割引率 A。判定は割引前の通常品小計Rで行い、会員ランクは問わない(一般会員も対象)。
  - R ≧ 20,000円 → A = 8%
  - 10,000円 ≦ R < 20,000円 → A = 5%
  - R < 10,000円 → A = 0%
  - 5%と8%は併用しない(該当する方のみ)。
- R7.(期間内のみ)誕生月加算割引率 B。会員ランクがシルバー以上(シルバー/ゴールド)かつ誕生月の場合のみ B = 3%。一般会員には付与しない。
- R8. 合計%割引率 P = M + A + B を上限でキャップする。
  - ゴールド かつ 誕生月 → 上限18%
  - それ以外 → 上限15%
- R9. %割引(P)はセール品Sには一切適用しない。通常品Rのみに適用する。

## 3. クーポンとの排他判定
- R10. 500円クーポンは%割引と同時併用不可。1会計につき使用できるクーポンは1枚のみ。
- R11. クーポンは期間外でも使用可。通常品・セール品どちらにも使え、通常品小計Rとセール品小計Sの合計(R+S)から500円を差し引く。
- R12. クーポン利用希望がある会計は、以下を比較し、支払額がより少なくなる方を実際に採用する。
  - (a)%割引額 = floor(R × P)
  - (b)クーポン割引額 = 500円(R+S<500円の場合の扱いは末尾参照)
  - (a)と(b)が同額の場合の優先順位は末尾参照。
- R13. クーポン利用希望がない会計は、%割引(R5〜R9)のみを適用する。

## 4. 商品代金(支払額)の算出
- R14. %割引を採用: 商品代金 =(R − floor(R×P))+ S
- R15. クーポンを採用: 商品代金 = R + S − 500

## 5. 送料
- R16. 送料が発生するのは配送の場合のみ。店頭受け取りは送料なし。
- R17. ゴールド会員は配送時、常に送料無料(期間・金額・クーポン利用有無を問わない)。
- R18. ゴールド以外が配送を利用する場合、R14の「割引後の通常品小計」(R − floor(R×P))が
  - 5,000円以上 → 送料無料
  - 5,000円未満 → 送料600円
  - ※クーポンを採用した会計(R15、%割引を使っていない)にこの基準をどう当てはめるかは末尾参照。本ルールでは暫定的に割引前のRをそのまま用いる。

## 6. ポイント付与
- R19. ポイント付与条件: 「期間内」かつ「当該会計でクーポンを採用していない」こと。
- R20. ポイント = floor(商品代金(送料を除く。R14の値)× 1%)
- R21. 期間外、またはクーポンを採用した会計はポイント付与なし。

## 7. 最終請求額
- R22. 最終請求額 = 商品代金(R14またはR15)+ 送料(R16〜R18、配送時のみ)

## 計算フロー(擬似コード)
```
in_campaign = (2026-12-01 <= 会計日 <= 2027-02-28)

M = {gold:0.10, silver:0.05, general:0.00}[rank]

A = 0.08 if (in_campaign and R >= 20000) else \
    0.05 if (in_campaign and R >= 10000) else 0.00

B = 0.03 if (in_campaign and rank in [gold, silver] and is_birthday_month) else 0.00

cap = 0.18 if (rank == gold and is_birthday_month) else 0.15
P = min(M + A + B, cap)

percent_discount = floor(R * P)                     # セール品には適用しない
coupon_discount  = min(500, R + S)                  # ※下限0円の扱いは要確認

if クーポン利用希望 and coupon_discount > percent_discount:
    use_coupon = True
elif クーポン利用希望 and coupon_discount == percent_discount:
    use_coupon = ???                                 # ※同額時の優先ルールは要確認
else:
    use_coupon = False

if use_coupon:
    merchandise_total = R + S - coupon_discount
else:
    merchandise_total = (R - percent_discount) + S

if not 配送:
    shipping = 対象外
elif rank == gold:
    shipping = 0
else:
    discounted_R_for_shipping = (R - percent_discount) if not use_coupon else R  # ※要確認
    shipping = 0 if discounted_R_for_shipping >= 5000 else 600

points = floor(merchandise_total * 0.01) if (in_campaign and not use_coupon) else 0

final_amount = merchandise_total + (shipping if 配送 else 0)
```

## 確認したい点
1.(R2)1円未満の切り捨ては、%割引額・ポイントなど各計算のたびに都度行う前提としました。最終合計のみで切り捨てる意図であれば教えてください。
2.(R12)%割引額とクーポン割引額(500円)が同額になった場合、どちらを優先しますか(採用方式によりポイント有無が変わるため重要です)。
3.(R12)クーポンの利用希望はどう判定しますか。顧客がその会計でクーポン利用を申告・提示した場合のみ比較対象とする前提でよいか、それとも条件を満たす会計には自動的に比較・適用されるものですか。
4.(R12)比較の結果%割引が採用されクーポンが使われなかった場合、そのクーポンは消費されず温存される(再利用できる)という前提でよいですか。
5.(R12・R15)R+Sが500円未満の少額会計でクーポンを使う場合、割引はR+S全額を上限とし、請求額の下限を0円とする前提でよいですか。
6.(R6)購入金額加算割引(通常品1万円以上で+5%、2万円以上で+8%)は、一般会員を含む全ランクに適用されるという理解でよいですか(メモにランク限定の記載がないため)。
7.(R16〜R18)送料ルール(5,000円以上無料/600円、ゴールドは常時無料)は、キャンペーン期間の内外を問わず通年適用という理解でよいですか(メモに「期間中」の限定がないため)。
8.(R18)クーポンを採用した会計(%割引0%相当)の送料無料判定には、割引前の通常品小計Rをそのまま用いる前提としましたが、それでよいですか。
9. 誕生月の判定は「会計日が属する月」が会員の誕生日の月と一致することを指す、という理解でよいですか。
