# 割引ルール仕様(冬のキャンペーン / 会計処理エージェント向け)

## 前提・スコープ
- 金額はすべて税抜。消費税の計算は本ルールの範囲外(本ルールの計算結果に対し、別途加算すること)。
- 計算過程で1円未満の端数が生じた場合は、その都度切り捨てる(floor)。
- ％割引(会員割引・キャンペーン加算・誕生月加算)は、期間の内外を問わず**セール品には一切適用しない**。常に「通常品」にのみ適用する。

## 入力項目(1会計あたり)
- 会計日
- 会員ランク: gold / silver / general
- 会員の誕生月(gold・silverの場合。1〜12)
- カート内商品リスト:各商品に「価格(税抜・割引前)」と「区分(通常品 / セール品)」
- クーポン利用希望の有無(true/false。1会計につき最大1枚。2枚以上の提示は1枚として扱い超過分は無効)
- 配送区分: 配送 / 非配送(店頭受取等)

## 用語
- 期間中: 会計日が 2026-12-01 〜 2027-02-28 の範囲内であること
- R: カート内「通常品」の価格(定価・割引前)の合計
- S: カート内「セール品」の価格の合計

## 計算手順

### ステップ1. 会員基礎割引率
- gold: 10%
- silver: 5%
- general: 0%

### ステップ2. キャンペーン加算率(期間中のみ、Rに基づき判定)
期間中の場合のみ、割引前のRの金額で判定する(期間外は常に+0%、セール品はRに含めない):
- R ≥ 20,000円 → +8%
- 10,000円 ≤ R < 20,000円 → +5%
- R < 10,000円 → +0%
※5%と8%は排他。両方を加算することはない(高い方のみ採用)。

### ステップ3. 誕生月加算(期間中のみ、シルバー以上)
「期間中」かつ 会員ランクが silver または gold かつ 会計日の月が誕生月と一致 する場合のみ:+3%
上記以外(generalの場合/期間外の場合)は+0%。

### ステップ4. 最終割引率の確定
合計割引率(素) = ステップ1 + ステップ2 + ステップ3
上限:
- 通常上限: 15%
- 例外: 会員ランクがgold かつ 誕生月に該当する場合のみ上限18%
最終割引率 = min(合計割引率(素), 該当する上限)
※誕生月加算自体が期間中にしか発生しないため、18%上限が意味を持つのも期間中のgoldに限られる。
※この最終割引率はRにのみ適用する。Sには適用しない。

### ステップ5. ％割引ルートとクーポンルートの算出
- ルートA(％割引、クーポン不使用):
  R_after = R − floor(R × 最終割引率)
  商品合計A = R_after + S
- クーポン利用希望がある場合のみ、ルートBも算出する:
  商品合計B = max(0, R + S − 500)
  (このルートでは最終割引率は適用しない。％割引とクーポンは併用不可のため)

### ステップ6. 採用ルートの決定
- クーポン利用希望がない場合: ルートAを採用。
- クーポン利用希望がある場合: 商品合計Aと商品合計Bを比較し、顧客の支払額が少なくなる方(小さい方)を採用する。同額の場合はルートAを採用する。
- 商品合計(確定) = 採用したルートの金額。
- ルートBが採用された場合、その会計では％割引は適用されていない扱いとする。

### ステップ7. 送料(配送の場合のみ発生)
- 非配送(店頭受取等)の場合: 送料 = 0円(本ルールの送料判定自体が対象外)。
- 配送の場合:
  - 会員ランクがgoldの場合: 送料 = 0円(期間・金額を問わず常に無料)。
  - それ以外の場合、判定基準額 = ステップ6で採用したルートにおける通常品の金額(ルートA採用時は R_after、ルートB採用時は R。ルートBでは％割引が適用されていないため)。
    - 判定基準額 ≥ 5,000円 → 送料0円
    - 判定基準額 < 5,000円 → 送料600円

### ステップ8. ポイント付与
次の両方を満たす場合のみポイントを付与する:
- 期間中である
- 採用ルートがA(クーポン未使用)である
ポイント = floor(商品合計(確定) × 1%)
上記いずれかを満たさない場合(期間外、またはクーポン利用による会計)はポイント = 0。

### ステップ9. 最終請求額
最終請求額 = 商品合計(確定) + 送料
(この後、別途消費税を加算する)

## 確認したい点

1. **％の合算方法**:「合計15%まで」を、各％(会員割引・キャンペーン加算・誕生月加算)を単純合算してから一度だけ上限でクリップし、その割合をRに一括で掛ける(個別に順次掛けて都度端数処理する方式ではない)という前提で計算しました。この理解で問題ないか確認をお願いします。

2. **クーポンとの「得な方」の比較基準**: 送料やポイントへの影響は考慮せず、商品代金(％割引後の商品合計 vs クーポン適用後の商品合計)のみで比較する前提としました。送料・ポイントも含めた総合的な金額で比較すべきかどうか確認をお願いします。また同額の場合はルートA(％割引)を優先する前提としましたが、この優先順位でよいか確認をお願いします。

3. **クーポンが不利と判定された場合の扱い**: ％割引ルートが採用された会計で、顧客が提示したクーポン自体は「未使用」として温存され、別の会計で再度使えるという前提でよいか(消費してしまうのか)確認をお願いします。

4. **通常品合計(1万円/2万円)の判定単位**: あくまで「その1回の会計」の合計であり、会員の月間累計購入額などは考慮しない前提です。この理解で問題ないか確認をお願いします。

5. **クーポンルート採用時の送料判定基準**: クーポンルートでは％割引が適用されていないため、送料の閾値判定には割引前の通常品合計Rをそのまま使う前提としました。この解釈で問題ないか確認をお願いします。

6. **クーポン適用後の合計がマイナスになる場合**: 0円までとする(それ以上は値引きしない)前提としましたが、この処理でよいか確認をお願いします。

7. **「一般」の定義**: 非会員(会員登録なし)を含むのか、登録はしているが無料/一般ランクという意味なのかを確認したいです(計算上はどちらでも割引率0%・誕生月加算対象外という扱いは変わらないため、計算結果への影響はありません)。
